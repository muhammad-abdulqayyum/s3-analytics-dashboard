Small responses. Large datasets.

The full project uses React, a Spring Boot API, Redis, and Athena querying partitioned Parquet data in S3. Requests return daily summaries rather than downloading the entire data lake.

What this public demo runs

All data is generated in your browser. The delayed query, request journey, and five-minute cache illustrate the application behavior. No AWS, Spring Boot, or Redis server is contacted by this page.

Run the full stack

Clone the GitHub repository and run docker compose up --build. The local demo runs real Spring Boot and Redis with synthetic data. Use the AWS profile to connect your own Athena workgroup, Glue Catalog, and S3 dataset.
